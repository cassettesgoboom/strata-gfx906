## AB/CD remains a separate draft

Upstream v0.2.10 contains no `STRATA_BATCH_ABCD` scheduler or `BatchTransactionRegistry`. Its pipelined MTP path is not the same scheduler and is not evidence of AB/CD support.

The fork's AB/CD source candidate is commit
[`0fffc4412ebd1ba5e5f880fdabaeb840a1164adc`](https://github.com/cassettesgoboom/strata-gfx906/commit/0fffc4412ebd1ba5e5f880fdabaeb840a1164adc), on `experimental/v0.1.41-abcd-source`, based on v0.1.41 commit
[`fb58e0dbc8399662c0e47c76578c6e878b14f6cf`](https://github.com/cassettesgoboom/strata-gfx906/commit/fb58e0dbc8399662c0e47c76578c6e878b14f6cf). Public [PR #4](https://github.com/cassettesgoboom/strata-gfx906/pull/4) remains a draft and the candidate is not fork main.

Fork main separately contains the CPU-side transaction registry from commits
[`a330a5ef`](https://github.com/cassettesgoboom/strata-gfx906/commit/a330a5ef), [`10e040b8`](https://github.com/cassettesgoboom/strata-gfx906/commit/10e040b8), [`3be734e8`](https://github.com/cassettesgoboom/strata-gfx906/commit/3be734e8), [`370bd50e`](https://github.com/cassettesgoboom/strata-gfx906/commit/370bd50e), and [`d2f34e4e`](https://github.com/cassettesgoboom/strata-gfx906/commit/d2f34e4e). The fork's [delta notes](https://github.com/cassettesgoboom/strata-gfx906/blob/main/docs/gfx906/UPSTREAM-DELTA.md) state that it is not wired into the verifier or scheduler and does not implement GPU completion, drain, recovery, or parity. It is a contract and test scaffold, not a completed AB/CD implementation.

A port needs a separate design and code review against current upstream verifier, scheduler, and session lifetimes. Keep AB/CD opt-in until a pinned current-source build passes runtime comparison of ordered native token IDs and persistent recurrent-state checkpoints against the serial path. Synthetic comparator equality and compile-only receipts do not satisfy that gate.
